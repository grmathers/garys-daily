"Faulty Memory": Continuous LLM Memory Updates Can Make Agents Worse Than No Memory

A new study finds that agent updates don't always make stored memories more useful — they can degrade them, leaving agents performing worse than the same model with no memory at all. The failure mode is in the rewrite step. Until agents can reliably decide when and how to consolidate, the safest default is episodic memory with sparse abstraction. A sober counterweight to the "give the agent a brain" reflex.
